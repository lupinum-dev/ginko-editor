# Get started with Ginko Editor

A portable Vue editor for Ginko content.

## Install

```bash
pnpm add @lupinum/ginko-editor @lupinum/ginko-content @tiptap/core @tiptap/pm @tiptap/vue-3
```

## Use the package

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { GinkoEditor } from '@lupinum/ginko-editor'
import '@lupinum/ginko-editor/style.css'

const source = ref('# Hello\n')
</script>

<template>
  <GinkoEditor v-model="source" />
</template>
```

The Markdown source is the canonical value. Opening the editor and changing
modes do not rewrite it. The editor keeps invalid or unsupported documents in
source mode so that visual editing cannot discard content.

## Write and insert blocks

Type `/` at the start of a paragraph, or select **Insert**. Search for a block,
use the arrow keys to choose it, and press Enter. Escape closes the menu and
returns focus to the document. Normal headings, lists, quotes, code, dividers,
tables, and image requests are available without a component kit.

An `authoring-kit` adds the host's component recipes to the same menu. Recipe
`keywords` provide aliases such as `/note`. An optional `description` explains
what the recipe does. Component titles and labels appear on the writing canvas;
select a component to edit its declared properties, duplicate it, or move it.

The `recipe-preview` slot receives `{ recipe }`. Use `recipe.source` with Ginko
Content's parser, the kit's policy, and your own registered render components to
show the real component. The editor does not import host components or choose
how they render. The playground demonstrates this integration,
including a component library and a live reader preview.

## Save and select assets

Your application owns saving and asset dialogs. Handle `request-image`,
`request-file`, and `request-video`. Complete the request with
`request.complete(asset)`, or `request.complete(null)` on cancellation.
Completion returns `false` when the original document or selection has changed.
Validate the chosen asset against your content contract before completing it.
Set `image-output="markdown"` for native Markdown image output.

Before navigation or document replacement, await the editor's `flush()` method.
Continue only when it returns `{ ok: true }`, then await your own save operation.
Keep the editor available when flush fails so the author can recover.

The playground saves drafts only in the current browser. It offers Write,
Split view, and Preview modes. Opening an example or a new page offers an Undo
action to recover the previous page. These host behaviors are examples, not
persistence services inside the editor package.

# Get started with Ginko Editor

A portable Vue editor for Ginko content.

## Install

```bash
pnpm add @lupinum/ginko-editor
```

## Use the package

```vue
<script setup lang="ts">
import { GinkoEditorScaffold } from '@lupinum/ginko-editor'
import '@lupinum/ginko-editor/style.css'
</script>

<template>
  <GinkoEditorScaffold />
</template>
```

The scaffold component is temporary. It proves that Vue code, declarations,
and explicit CSS imports work before the editor moves into this package.
